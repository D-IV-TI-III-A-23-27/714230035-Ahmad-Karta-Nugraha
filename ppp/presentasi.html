Landasan Teori

Apa itu Principal Component Analysis?

Definisi

PCA adalah teknik statistik untuk mereduksi dimensi data tanpa kehilangan terlalu banyak informasi. Caranya dengan menemukan sumbu koordinat baru yang memaksimalkan varians data.

Tujuan Utama
  • Mengurangi kompleksitas dataset
  • Menghilangkan redundansi antar variabel
  • Memudahkan visualisasi data dimensi tinggi
  • Menekan noise tanpa kehilangan sinyal utama
Analogi Sederhana

Bayangkan Anda memotret bayangan sebuah benda 3D. Foto (2D) adalah hasil reduksi dimensi yang masih mempertahankan bentuk esensial benda tersebut.

PCA bekerja persis seperti itu — ia mencari "sudut kamera terbaik" agar proyeksi yang tersisa mengandung informasi maksimal.

Langkah Perhitungan

Alur Algoritma PCA

01

Mean Centering — Pusatkan Data

Hitung rata-rata seluruh titik, lalu geser koordinat sehingga centroid berada tepat di (0, 0). Tanpa langkah ini, komponen utama akan bias ke arah mean.

02

Hitung Matriks Kovarians — C

Ukur seberapa besar dua dimensi "bergerak bersama". VAR(X), VAR(Y), dan COV(X,Y) membentuk matriks simetris 2×2.

03

Eigen-Decomposition — C·v = λ·v

Temukan eigenvector (arah komponen utama) dan eigenvalue (besar varians yang dijelaskan). Eigenvalue terbesar → PC1, sisanya → PC2.

04

Explained Variance Ratio — λ / Σλ

Hitung proporsi informasi setiap komponen. Jika PC1 ≥ 95%, maka PC2 dapat direduksi dengan kehilangan informasi <5%.

04 / 10
Detail Matematis

Matriks Kovarians

C = COVARIANCE MATRIX
[
VAR(X) = σ²ₓ Cₓₓ
COV(X,Y) Cₓᵧ
COV(Y,X) Cᵧₓ
VAR(Y) = σ²ᵧ Cᵧᵧ
]

Simetris: Cₓᵧ = Cᵧₓ

Cₓₓ = Σ(xᵢ − x̄)² / (n−1)
Varians dimensi X — seberapa lebar data tersebar di sumbu X
Cₓᵧ = Σ(xᵢ − x̄)(yᵢ − ȳ) / (n−1)
Kovarians — kekuatan korelasi linier antara X dan Y

Kovarians besar → titik-titik tersusun diagonal → PCA sangat efektif untuk reduksi dimensi.

05 / 10
Inti Algoritma

Eigen-Decomposition

C · v = λ · v
Matriks kovarians C dikalikan vektor eigen v menghasilkan vektor yang searah dengan v namun berskala sebesar eigenvalue λ. Ini berarti v adalah arah di mana data "meregang" sebesar λ.

PC1 — Eigenvector Utama

λ₁ (besar)
Arah di mana varians data MAKSIMAL. Ditampilkan sebagai garis Cyan di visualisasi. Mempertahankan informasi terbesar.
~75%–95% varians dijelaskan

PC2 — Eigenvector Kedua

λ₂ (kecil)
Arah tegak lurus PC1. Menjelaskan sisa varians. Ditampilkan sebagai garis Putih di visualisasi. Kandidat untuk direduksi.
~5%–25% varians tersisa

Implementasi

Fitur Aplikasi

⚙️

Kontrol Parameter Real-time

4 slider interaktif: Density (10–1000 pts), Spread X, Spread Y, dan Rotation α (−90° hingga +90°). Grafik diperbarui seketika tanpa reload.

📊

Visualisasi SVG Dinamis

Ribuan titik data Gaussian dirender via SVG langsung di DOM. Eigenvector ditampilkan sebagai panah beranimasi dengan marker-end yang berubah sesuai parameter.

🔢

Panel Eigen-Decomposition

Menampilkan nilai eigenvalue λ₁ dan λ₂, persentase explained variance PC1 & PC2, serta bar chart mini (Scree Plot) yang diupdate secara live.

📐

Tabel Matriks Kovarians

Nilai VAR(X), VAR(Y), dan COV(X,Y) tampil live di panel bawah layar.

🔄

Recalculate / Reseed Data

Tombol "Recalculate Projections" men-generate ulang 1000 sampel Gaussian acak baru, sehingga pengguna dapat mengamati stabilitas PCA pada berbagai sampel.

📖

Halaman Penjelasan

Tab "Penjelasan" berisi narasi edukatif tentang konsep PCA: definisi, langkah algoritma, cara membaca grafik, dan interpretasi Scree Plot — tanpa perlu meninggalkan aplikasi.

Analisis Hasil

Membaca Scree Plot & Explained Variance

Contoh: Spread X=8, Spread Y=1, Rotation=30°
100% 0%
94.3%
PC1
5.7%
PC2

λ₁ / (λ₁ + λ₂) = 0.943
λ₂ / (λ₁ + λ₂) = 0.057

◆
PC1 ≥ 95% → PC2 bisa dihapus (reduksi ke 1D) dengan kehilangan <5% informasi. Cocok untuk data memanjang.
◆
PC1 ≈ 50% → data berbentuk melingkar / isotropis. Kedua komponen sama pentingnya, reduksi tidak disarankan.
◆
Rotation α naik → korelasi antara X dan Y bertambah → Cₓᵧ membesar → eigenvector PC1 berputar mengikuti arah data.
◆
Density rendah → eigenvalue tidak stabil antar reseed. Density tinggi → hasil lebih konsisten dan terprediksi.

Penutup

Kesimpulan

01
PCA adalah algoritma reduksi dimensi berbasis aljabar linear yang menemukan sumbu baru (principal components) sejajar dengan arah varians terbesar dalam data.
02
Aplikasi ini berhasil mengimplementasikan seluruh pipeline PCA — dari distribusi Gaussian, mean centering, matriks kovarians, hingga eigen-decomposition — murni menggunakan JavaScript tanpa library.
03
Melalui visualisasi interaktif, pengguna dapat secara langsung mengamati bahwa Rotation (korelasi) adalah faktor utama yang menentukan efektivitas PCA sebagai teknik reduksi.
04
Ketika Explained Variance PC1 ≥ 95%, reduksi ke satu dimensi dapat dilakukan dengan kehilangan informasi minimal — ini adalah inti kegunaan PCA di dunia nyata (Computer Vision, NLP, Bioinformatika).
05
Proyek ini menunjukkan bahwa konsep matematis abstrak dapat disajikan secara intuitif dan interaktif melalui web modern dengan teknik rendering SVG real-time.
